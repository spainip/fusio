# Fusio API gateway

Fleet-managed Fusio API management deployment for spainip.es.

- API and Fusio public service: https://api.spainip.es
- Fusio administration: https://api-admin.spainip.es/apps/fusio
- Mock API documentation: https://api.spainip.es/docs/

Secrets are created directly in the cluster and are not stored in this repository.
